# Almare Parafarmacia

Web premium para Almare Parafarmacia, Chiclana de la Frontera.

## Desarrollo

Abre `index.html` directamente en el navegador, o ejecuta un servidor estático en esta carpeta.

## Reservas

El formulario valida los campos y prepara la solicitud en WhatsApp. Sustituye `WHATSAPP_NUMBER` en `app.js` por el teléfono real del negocio, en formato internacional y sin `+` ni espacios. No hay un sistema de citas conectado: las solicitudes se envían como mensaje para confirmación manual.

## Contenido

Textos y servicios desarrollados a partir del documento de requisitos facilitado para la web. Verifica los servicios concretos que ofrece el equipo antes de publicar como promesa comercial.
